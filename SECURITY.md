# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/widgora/widgora/security/advisories/new)).

Do not open a public issue, pull request or discussion for a security problem.

Include what you found, the affected version or commit, and the steps to reproduce it. You will get an answer in
the advisory thread; fixes are released with a published advisory once a patched version is available.

## Supported versions

Widgora is in early development. Only the latest release and `main` receive security fixes.
